conditional statements in Python:

--> these conditional statements can be controlled using 

# LOOP controlled statements

# break , continue , pass

--> break

for j in range(3):
    if j == 2 :
        break;    #using break to break the loop for a particular condition
    # Start for
    print(j)

--> continue

for j in range(3):
    if j == 2 :
        continue;    #using continue at that number avoinding that number
    # Start for
    print(j)

--> pass

for j in range(3):
    if j == 2 :
        pass;    #using pass itworks as it is as for loop
    # Start for
    print(j)

--> Nested Loops:

# Outer loop
for i in range(3):
    print("Outer loop i =", i)
    
    # Inner loop
    for j in range(3):
        if j == 2:
            continue   # skip when j == 2
        print("   Inner loop j =", j)


--> nested loops working with Iterations:


for i in range(1, 6):
    
    for j in range(1,3):
        print(f"j:{j} and i:{i}")
